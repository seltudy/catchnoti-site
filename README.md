# catchnoti-site

캐치노티의 지원 페이지와 개인정보 처리방침이다. GitHub Pages가 main 브랜치의 파일을 빌드 없이 그대로 올린다 (`.nojekyll`).

| 주소 | 파일 |
|---|---|
| https://seltudy.github.io/catchnoti-site/ | `index.html` (지원) |
| https://seltudy.github.io/catchnoti-site/privacy/ | `privacy/index.html` (개인정보 처리방침) |
| https://seltudy.github.io/catchnoti-site/en/ | `en/index.html` |
| https://seltudy.github.io/catchnoti-site/en/privacy/ | `en/privacy/index.html` |

- 한국어가 기본이고 영어를 함께 둔다. 한쪽을 고치면 다른 쪽도 고친다.
- 자주 묻는 질문은 앱의 자주 묻는 질문(`Modules/Sources/SettingsUI/HelpView.swift`)과 같은 문구를 쓴다.
- 처리방침은 앱이 실제로 하는 일(네트워크 요청, 문의 메일의 진단 정보)과 맞춘다. 내용을 바꾸면 시행일도 고친다.
- 비슷한 다른 앱의 이름이나 내용을 쓰지 않는다.
